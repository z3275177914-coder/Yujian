# 玉鉴开源版隐私与数据处理说明

文档状态：当前实现说明

适用版本：`0.4.7` 及之后遵循同一数据边界的版本

更新日期：2026-09-03

本文描述玉鉴源码当前实现的本地数据、网络请求和外部工具边界，供用户在构建或使用开源版本前审阅。它不是针对某一国家或地区的法律意见，也不替代用户自行选择的云服务商隐私政策、服务条款和数据保留说明。

## 一句话结论

玉鉴以本地图片查看为默认模式：打开、浏览、缩放、平移、缩略图、元数据读取、基础编辑、导出和本机 OCR 默认在本机完成。应用不会因为用户打开或浏览普通图片而自动上传图片。只有用户主动使用云端 AI、ChatGPT 交接或配置并调用外部本地工具时，数据才会离开应用的本地处理边界。

## 数据处理总览

| 功能 | 处理的数据 | 默认位置或去向 | 触发条件 | 用户控制 |
| --- | --- | --- | --- | --- |
| 普通浏览和元数据 | 图片文件、文件属性、ImageIO 元数据 | 用户原始路径；解码主要在内存 | 用户打开文件或文件夹 | 用户选择文件；可在设置清理图片缓存 |
| 缩略图和解码缓存 | 缩略图、代理图、解码后的内存对象 | macOS Caches 下的应用缓存 | 浏览图片或生成缩略图 | 缓存有大小/有效期边界，可清理；缓存不是用户原图归档 |
| 动态照片播放 | 外部 MOV 或图片尾部声明的 MP4 片段 | 播放时使用；嵌入视频会按声明范围提取到受限缓存 | 检测到有效动态照片并单击播放 | 缓存可被系统清理，应用不会把视频上传到云端 |
| 编辑和导出 | 原图、编辑配方、导出结果 | 原图保持不变；结果写入用户选定位置 | 用户调整并选择导出/另存为 | 导出格式、尺寸、质量和 GPS 处理由用户选择 |
| 本机 OCR | 当前图片或选区 | macOS Vision 本机处理 | 用户选择“识别文字” | 不需要 API Key，不发起云端 AI 请求 |
| 云端 AI 分析 | 用户选择的图片内容、选区和提示词 | 用户配置的 Provider 接口 | 用户同意后主动执行 | 首次使用提示、撤销同意、删除历史、保留期限 |
| ChatGPT 交接 | 图片文件路径、图片 TIFF 数据和提示词 | macOS 系统剪贴板，再由用户粘贴到 ChatGPT | 用户主动点击 ChatGPT 交接 | 用户手动粘贴/提交，可选择 30 秒清理剪贴板 |
| 本地工具桥接 | 受权限控制的图片路径、文件名、尺寸、元数据 | 调用方与玉鉴之间的本机 URL/通知响应 | 用户开启对应权限且调用 `yujian://tool/...` | 权限默认关闭；`open_image` 每次确认 |

## 本地数据和生命周期

### 原图与普通查看

玉鉴读取用户选择的原始图片，不会为了普通查看复制一份原图到应用目录。大图使用降采样、代理图和瓦片/内存缓存来降低交互内存压力；这些缓存用于性能，不应被视为用户的备份。

当前实现使用的典型缓存位置如下，实际基础目录由 macOS 返回：

- 普通缩略图：`~/Library/Caches/ImageViewer/Thumbnails-v1/`
- 动态照片提取缓存：`~/Library/Caches/io.github.z3275177914-coder.yujian/MotionPhoto/`
- AI 临时输入：系统临时目录下的 `ImageViewerAI/`
- AI 历史：`~/Library/Application Support/ImageViewer/AIHistory/`
- 偏好设置：macOS UserDefaults；不会写入项目仓库
- API Key：macOS 钥匙串，不写入项目仓库或普通配置文本

普通缩略图缓存默认有 512 MiB 上限和 30 天有效期；动态照片提取缓存默认有 512 MiB 上限并按访问情况淘汰。缓存中的路径摘要用于区分源文件，不能据此恢复图片内容。应用设置中的“清理图片缓存”会清理内存解码缓存和普通磁盘缩略图缓存；动态照片缓存仍属于可重建的 macOS Caches 数据。

AI 历史可能记录原图绝对路径、操作名称、提示词、文字结果、输入来源和输入字节数。AI 图片编辑结果会以 PNG 保存在 AI 历史目录。历史默认永久保留，但用户可以选择 7 天、30 天或 90 天，逐条删除或全部清空。历史保留期限改变后，过期记录会被清理。应用不对本地历史作额外加密承诺；文件权限、FileVault 和备份策略由用户的 macOS 账户和系统配置决定。

AI 临时输入在请求结束后会清理；如果应用被强制终止、崩溃或系统中断，临时文件可能短时间残留在系统临时目录，用户可按 macOS 的临时文件管理方式处理。

### 编辑、导出和元数据

编辑采用非破坏式编辑配方。调整、裁剪、旋转和翻转首先只改变预览状态，原图不会被预览流程覆盖。导出默认写入用户在保存面板中选择的目标，并使用临时文件和原子替换避免半写文件。

导出默认保留可由 ImageIO 读取的元数据；用户可以选择“剥离 GPS 位置”。剥离 GPS 不代表所有软件自定义字段都被移除，因此公开分享前仍应由用户检查导出文件。详细格式、动画和导出限制见 [`IMAGE_FORMAT_SUPPORT.md`](IMAGE_FORMAT_SUPPORT.md)。

## 云端 AI

### 同意和触发

- 云端 AI 同意默认关闭。
- 首次执行云端分析、描述、说明或 AI 编辑前，应用会显示提示；取消不会发起该请求。
- 本机 OCR 不属于云端 AI，不需要同意或 API Key。
- 用户可在设置中撤销同意；下一次使用云端 AI 时会再次提示。
- 连接测试是用户主动发起的网络请求，会向所选 Provider 发送认证信息，但不会附带图片内容。

### 发送内容

当前云端分析流程会将图片或选区在本机重新编码为 JPEG，最长边上限为 2048 像素；OpenAI 图像编辑使用 PNG，最长边同样受 2048 像素限制。请求还包含用户输入的提示词。应用当前不会把原始文件路径作为云端 AI 请求字段发送，但图片内容本身可能包含 EXIF 以外的可识别信息；发送前应由用户确认图片适合交给对应服务商。

云端 AI 返回的文字结果和 AI 编辑图片可能被保存到本机 AI 历史。OpenAI 图像编辑在服务返回下载地址时，应用会按该地址下载生成结果；该地址的处理由 OpenAI 服务控制。

### Provider 和接口边界

当前实现包含以下 Provider：

| Provider | 默认接口 | 当前支持 | 项目侧约束 |
| --- | --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | 图片询问、描述、说明、图片编辑 | API Key 保存在钥匙串 |
| DeepSeek | `https://api.deepseek.com` | 图片询问、描述、说明 | 使用 OpenAI 兼容的分析请求 |
| Anthropic Claude | `https://api.anthropic.com/v1` | 图片询问、描述、说明 | 图片编辑当前不支持 |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` | 图片询问、描述、说明 | 图片编辑当前不支持 |
| 自定义 OpenAI 兼容接口 | 用户填写 | 图片询问、描述、说明 | 默认要求 HTTPS；仅 `localhost`、`127.0.0.1`、`::1` 可使用 HTTP |

Provider 的服务端日志、训练使用、保留期限、跨境传输、区域存储和删除机制不由玉鉴决定。启用某个 Provider 前，用户应阅读该 Provider 当前的隐私政策和服务条款，并确认其是否允许处理自己的图片、文字和个人信息。自定义接口尤其需要用户自行确认接口运营者可信。

API Key 的保存、读取和删除通过 macOS 钥匙串完成；Provider、模型和自定义接口地址保存为本机配置。项目不会把 Key 写入源码、Git、发布 ZIP、AI 历史或日志。若从旧版本升级，应用会在不改变 Key 内容的前提下兼容迁移旧 Bundle Identifier 下的钥匙串项目；旧项目数据不会被上传。

## ChatGPT 桌面端交接

ChatGPT 交接不是应用内直接提交聊天。玉鉴会：

1. 清空系统剪贴板当前内容。
2. 写入提示词、图片文件 URL 和可用的 TIFF 图像数据。
3. 尝试打开 ChatGPT 桌面端；找不到时打开 `https://chatgpt.com/`。
4. 等待用户在聊天框粘贴并由用户自行提交。

应用不会读取或记录 ChatGPT 的回复。若开启设置中的“ChatGPT 交接后 30 秒清理剪贴板”，只有在剪贴板内容仍未被其他程序改变时才会清理，避免误删用户之后复制的内容。系统剪贴板在清理前可能被其他具有剪贴板访问能力的程序读取，这不由玉鉴控制。

## 本地工具桥接

本地桥接使用 `yujian://tool/...`；为兼容旧集成也接受 `imageviewer://tool/...`。桥接权限默认关闭，分为：

- 读取当前图片和元数据；
- 列出当前文件夹图片；
- 请求打开图片。

响应可能包含绝对路径、文件名、扩展名、尺寸、文件大小、修改时间和 ImageIO 元数据。`open_image` 即使已开启权限，也必须逐次确认。桥接不提供任意目录遍历、任意文件写入或自动上传能力；调用方如何保存、转发或记录响应不属于玉鉴控制范围。

## 文件操作和系统边界

打开文件、选择文件夹、另存为和导出都由 macOS 文件面板发起。重命名、复制和移动只在用户选择的路径上执行；删除操作使用 macOS 废纸篓，必须先确认，默认不永久删除。应用不包含账户系统、云同步、广告、行为分析或第三方崩溃上报 SDK。

玉鉴使用 macOS ImageIO、Vision、Core Image、AVFoundation、AppKit 和系统文件能力。系统可能在用户授权的文件访问、剪贴板、Finder、网络或外部应用交互中记录自己的系统日志；本文只描述玉鉴代码主动执行的边界。

## 用户自查清单

在处理敏感图片时，建议：

- 不启用云端 AI，或先撤销/检查图片中的敏感内容；
- 使用“剥离 GPS 位置”导出副本，并检查导出文件；
- 在设置中删除 AI Key、清空 AI 历史和清理图片缓存；
- 使用 ChatGPT 交接后确认剪贴板不再包含图片；
- 只为可信的本地工具开启相应桥接权限；
- 阅读所选 Provider 的当前隐私政策、服务条款和数据保留说明。
